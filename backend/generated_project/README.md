# Project Root

This is the root directory for a project with:
- React frontend
- Gatsby frontend
- Python (FastAPI) backend

## Running the React Application

This project includes a React application located in the `frontend/react-app/` directory. Follow these steps to navigate, install dependencies, and run it locally:

1.  **Navigate to the React Application Directory:**
    Open your terminal or command prompt and change your current directory to the React application's root:
    ```bash
    cd frontend/react-app
    ```

2.  **Install Dependencies:**
    Once inside the `frontend/react-app/` directory, install the necessary Node.js packages. It's recommended to use `npm` or `yarn`.

    **Using npm:**
    ```bash
    npm install
    ```

    **Using yarn (if installed):**
    ```bash
    yarn install
    ```

3.  **Run the React Application:**
    After installing dependencies, you can start the development server. The application will typically open in your browser at `http://localhost:3000` (or another available port).

    **Using npm:**
    ```bash
    npm start
    ```

    **Using yarn:**
    ```bash
    yarn start
    ```

    You should now be able to interact with the React application and test the implemented feature (e.g., the background color change functionality).
